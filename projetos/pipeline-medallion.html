O projeto

Este pipeline simula a sincronização de uma origem SQL Server com o BigQuery. A ingestão em Python identifica registros novos, alterados e removidos; o Dataform organiza as transformações analíticas.

Proposta e estrutura

A camada Bronze recebe os dados de origem. A Silver normaliza e tipa os registros. A Gold consolida os dados para análise, incluindo dimensões temporais e métricas.
